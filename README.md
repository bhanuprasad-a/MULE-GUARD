# MuleGuard

Explainable Real-Time UPI Mule-Account & Fraud Investigation System.

## Project Goal

MuleGuard is a student-built fraud investigation platform designed to detect persistent mule-like transaction behaviour using transaction-level machine learning, temporal graph analysis, explainability, and investigation workflows.

## Current Phase

Phase 1 — Project setup and virtual-bank foundation.

## Planned Architecture

Virtual Bank ? Transactions ? Behaviour Features ? ML ? Graph Analysis ? Risk Engine ? Explainability ? Investigation

## Development Principle

The project is being developed as a college project with startup-grade engineering foundations.

## Data

The initial development environment will use synthetic transaction data and a simulated virtual bank. No real customer banking data will be used.

## Status

Early development.
